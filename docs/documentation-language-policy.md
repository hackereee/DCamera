# 文档语言规范（中文优先）

## 目标

统一仓库文档语言，降低沟通成本，保证团队在需求、设计、实现、测试与交付上的表达一致性。

## 规则

1. 所有文档默认使用中文。
2. 英文只用于以下场景：
   - 技术专有名词（如 Camera2、AVCaptureSession、bgfx、MediaCodec）。
   - 代码标识符、命令、路径、协议字段。
   - 必须引用的原始英文规范内容。
3. 若同时提供中英文版本，中文版本必须先更新且为主版本。
4. 新增文档、PR 描述、设计文档、实施计划、测试结论均执行中文优先。

## 写作建议

- 结构先中文，再在括号中给出英文术语。
- 避免中英混杂句式；一段内以中文叙述为主。
- 关键结论、风险、验收标准必须用中文明确表达。

## 执行范围

- `README.md`
- `docs/` 下所有 Markdown 文档
- 未来新增的设计文档、实施计划、测试报告

## 例外

- 第三方许可证文本（如 `LICENSE`）可保持原文。
- 外部依赖的官方引用可保留英文，但应有中文解释。
